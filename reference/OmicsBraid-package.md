# OmicsBraid: cross-omics effect concordance and heterogeneity

OmicsBraid is a research-oriented framework for cross-layer inference
from matched bulk multi-omics studies. Its core estimand is the vector
of standardized group effects for the same biological entity/pathway
across ordered omics layers. It is intentionally not a raw-data
preprocessing or latent-factor integration package. Robust empirical
calibration is available for the omnibus and heterogeneity tests when
asymptotic chi-square reference distributions are questionable.
