# Plot an Omics Evidence Forest

Plot an Omics Evidence Forest

## Usage

``` r
plot_evidence_forest(result, entity, omic_order = result$settings$omic_order)
```

## Arguments

- result:

  An \`omics_braid_result\`.

- entity:

  Entity/pathway to display.

- omic_order:

  Optional omic order.

## Value

A ggplot object.
